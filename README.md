# CS624-PE03-Enzo-Nguyen

Users enter a task 1, task 2,... into a text input field and press the Add/Submit button. The application retrieves the content from the input field and displays it on the interface. Users can also click one of three buttons: "All," "Incomplete," or "Completed" to filter the list of tasks.

The application uses React Native to build the user interface. As the user types into the input field, the "inputChange" function captures the text. When the user presses the Add/Submit button, the "submitTodo" function checks whether the input field is empty. If it contains text, the application creates a new task and adds it to the list of todos. Each task consists of a name, an index number, and a completion status (complete or incomplete). The application then clears the input field so the user can enter the next task. The "toggleComplete" function updates a task's status when the user marks it as completed. The application provides three filter buttons: "All," "Incomplete," and "Completed."

New tasks appear on the screen, directly below the input field. Users can view all tasks by selecting "All," see only unfinished tasks by selecting "Incomplete," or view only completed tasks by selecting "Completed." Users can also delete tasks that are no longer needed.
